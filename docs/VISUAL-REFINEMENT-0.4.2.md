# Noah 0.4.2 · 磨砂材质与中性配色

2026-10-03，针对“毛玻璃不明显、配色不协调”的桌面修订。

## 判断与设计

当前问题不是圆角数量不足。v0.4.1 的原生 sidebar 已经使用窗后混合，但叠加的蓝灰色、偏实的系统材质和失焦状态使透色很弱。悬停、选中和新建入口共用同一个表面；深色背景、文字和阴影同时偏蓝，也削弱了层次。

采用瓷白 / 石墨阅读面、系统磨砂导航、少量帆船蓝操作色。保持系统字体、原生窗口控制、用户选定的帆船和官方 Harness 标识，保留已有讨论、草稿、通信与权限行为。

| --- | --- | --- |
| 阅读画布 | `#fbfbfc` | `#202124` |
| 提升表面 | `#ffffff` | `#2b2d32` |

## 实现契约

1. Electron 使用 `under-window` vibrancy 和 `followWindow`。逻辑 `data-window-material="sidebar"` 保持，避免混淆原生枚举与前端材质状态。未设置 `transparent:true`，保留正常原生窗口边缘与控制。
2. 页面在原生材质可用时只覆盖 16% 浅色 / 24% 深色中性底色。主讨论画布仍实色，导航和宽窗详情透出窗后材质。没有添加假壁纸或彩色背景图。
3. 导航拆分 hover、selected、new-action 表面；选中使用轻蓝、标题字重与顶缘高光共同识别。蓝色主操作、焦点和继续协作控件遵循同一色阶。
4. 弹窗、窄窗详情及 toast 采用有底色的磨砂层，局部 `blur(28px) saturate(125%)`；正文、主输入和文本字段优先清晰可读。半透明度不能被当作对比度证明。
5. 保留 11px 控件、16px 面板、22px 编辑框的圆角层级；阴影改为中性灰。创建弹窗保留独立滚动区和固定底部操作；重新打开时回到顶部，避免标题被上次的滚动位置藏住。
6. 系统减少透明度通过 native metadata 与 CSS media query 两条路径关闭透明模糊；不支持 backdrop-filter 的浏览器使用实色浮层。减少动画、键盘焦点和快捷键保留。
