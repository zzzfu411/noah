# Working on Noah

Noah is a standalone macOS desktop application. Electron hosts the HTML/CSS/JavaScript frontend; the local browser entry is for development. Preserve equal Grok/pi participation, explicit context sharing, truthful delivery states and durable task/draft recovery.

The current product target is automatic harness discovery and discussions mixing existing work sessions with newly created sessions. See SPEC.md D14–D20 and docs/GOAL-V0.4-SPEC.md. The user chose full shared-discussion delivery to the original session; do not silently switch to summaries. New discussions default to autonomous peer exchanges without an aggregate run/time cap; limits and nullable new-input byte budgets are optional owner controls. Preserve existing limits and paused states unless the owner explicitly changes them. Empty queues mean idle, not confirmed consensus or task completion. Keep timeout, cancellation, uncertain-delivery and per-run tool-call protections separate; do not claim a semantic loop detector exists.

v0.4 supports independent Grok/pi participants, connected original-process pi sessions, and membership changes after creation. shareHistory controls passive automatic backfill, not access to public history. Retain removed identities and in-flight evidence; refuse removed members' new scoped tools and dispatch without killing their external process. Archive preserves history, restore stays paused, and asynchronous failures must not undo an archive. Materials use immutable revisions. Outcomes are separate durable proposals with same-discussion evidence; only authors revise and only the owner confirms a version. Confirmation is not consensus or completion, and proposals are read actively by Agents rather than automatically broadcast. Workspace authorization shares an explicit path for advisory intentions, not filesystem permission, a scan or a file lock. Compact state must retain full-history metrics and make private output/old receipts available through pagination. System notifications default to off and never include discussion bodies.
